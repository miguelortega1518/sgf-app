# Gráficos: capturas de QA deben incluir la sección

Panorama es una página larga y las capturas de QA se cortan antes de «Flujo de trabajo», así que el revisor ui no ve los gráficos. Al añadir una sección nueva a una página larga, captura el elemento concreto o con scroll/full-page, no sólo la parte superior.
